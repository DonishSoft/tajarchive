# Code of Conduct

TajArchive is a community project. Everyone taking part — in issues, pull requests,
discussions or anywhere else — is expected to:

- be respectful and patient, especially with newcomers and people writing in a
  language that is not their first;
- discuss ideas, not people; criticism of code is welcome, insults are not;
- not harass, threaten or discriminate against anyone for any reason;
- not post other people's private information.

Maintainers may edit or remove comments, close issues and block participants who do not
follow these rules. To report a problem privately, write to info@donishsoft.com.
