# Security

TajArchive opens files that come from anywhere, so security reports matter to us.

Please **do not** open a public issue for a security problem. Write to
**info@donishsoft.com** with the subject "TajArchive security", describe the problem and,
if you can, attach a file or steps that reproduce it. We will reply within a week and
credit you in the release notes unless you prefer otherwise.

Problems in the 7-Zip engine itself should also be reported to its author through
<https://www.7-zip.org/>; we update the bundled engine when fixes are released.
